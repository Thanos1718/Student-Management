Fullstack Web application utilizing Angular 16 and Spring boot 3 to fascilitate features like Sign in with google, password reset using spring security, SMTP , JMS and Java 8.
Implemented various design patterns like builder, proxy and factory in order to build scalable , robust and secured web application.
Designed and developed highly interactive web pages handling smooth navigation , UI/UX and routing using auth guards , 2 way data binding and Depedency injection of Angular.
Leveragged HTTP clientAPI to securely communicate with backend enabling CORS policies and prevent various types of attacks by JWT based authentication and role based authorization.
Role based access to various resouces enabling permissions based on User role.
